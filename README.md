# developer-insights-analysis
Data analysis project exploring global developer trends with focus on AI adoption, remote work, and tech stacks.

## Key Findings
- Python is the #1 language for the 4th consecutive year
- 70%+ of developers now use AI tools in their workflow
- Remote work remains dominant in tech post-2023
- ChatGpt is the most used IA dev
- the age of the most developers are around their 20s
- USA has the most of the dataset responds
